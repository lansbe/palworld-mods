# Screenshot notes

These are real, unretouched captures from the Mac App Store edition of Palworld,
using Palworld Mods, Minimap 0.2.1 and Autonomy 0.2.1 on game build 102999.
The native menu capture uses Mods 0.4.4; the gameplay capture uses Mods 0.4.2.
The game and mod interface were temporarily set to English for documentation.
The captures were taken on October 13, 2026, at the title screen and in a local test world.

Images show the native Mods settings, Minimap during gameplay, or the relevant
mod settings. Autonomy was stopped throughout the session. A screenshot shows
appearance; it is not evidence of a complete autonomous capture/gathering session
or multiplayer behavior. Minimap is a separate optional companion for MCP and
Autonomy, not a feature implemented by those projects.

The JPEG files are direct window captures, without compositing, generated UI,
or extracted game textures. They were reviewed for visible player names,
invitation codes, desktop content and identifying metadata before publication.

Palworld and the game artwork/interface visible in these documentation images
remain the property of their respective owners. The project's MIT license
covers its original code, not the depicted game content. Do not package these
screenshots as game assets.

When replacing a capture, use the actual released application, review the whole
image and its metadata, keep it below 2 MiB, and update these version notes.
